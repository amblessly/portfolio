About

I build practical software — things that run, get used, and hold up outside a demo.

I'm Blessly, a Computer Science student based in Muntinlupa City, Philippines. My work sits at the seam between full-stack web development and embedded systems: software that talks to sensors, radios, and real people — not just browsers.

Recent work spans AERIS, an off-grid UAV search-and-rescue program pairing on-device YOLOv8n detection with dual-link 5GHz Wi-Fi and LoRa telemetry; SmartQueue, a queueing system built for students at Pamantasan ng Lungsod ng Muntinlupa; and DELTA, a student identification and health-data workflow rendered on a kiosk dashboard.

I'm currently sharpening software engineering fundamentals — data structures, algorithms, and the discipline of shipping end-to-end, from circuit to deployment.

Edge-AI · Search & Rescue 01 / AERIS

AERIS — Off-Grid UAV Search & Rescue

An off-grid, dual-link search-and-rescue system. A 5GHz Wi-Fi link streams live video while 915/923MHz LoRa carries telemetry, and survivor detection runs on-device — YOLOv8n on a Raspberry Pi 5 with a Hailo-8L NPU — targeting under 105ms end-to-end latency for the golden hour after a disaster.

  • Python
  • TypeScript
  • YOLOv8n
  • FastAPI
  • LoRa 915MHz
  • Raspberry Pi 5
Live Dashboard Repository Research prototype · updated Sep 2026

  2. 02

  3. 03
    RespondSurvivor GPS coordinates to the ground-station dashboard

  • 10–200m trial range
